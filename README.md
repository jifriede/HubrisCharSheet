# HubrisCharSheet
Local browser-based character sheet for my TTRPG *Hubris of the Gifted*  
You can enter your character information into the HTML character sheet, then press the save button to download a .json file which stores your character's information. The next time you open the HTML character sheet, you can upload the file to repopulate the values.  
There is also local browser-based storage, which allows you to save and reopen characters without downloading a .json file.
